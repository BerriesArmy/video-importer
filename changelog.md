# v0.1.1

Moved the Video button so it no longer covers Ignore Damage. Single pictures now use a shared color palette and a larger grid, so they come out much sharper, and they hold for a set number of seconds instead of ending right away. The window after import shows the length and object count. Imports respect the editor object limit and are cut short with a warning when they would go over. Added hide ground, disable controls and a black background that also hides the ground, using the real Options trigger properties. Loop and end level now switch each other off. The end trigger is also placed at the end of the video, and the default video size is smaller.

# v0.1.0

First release. Imports GIFs, single images and folders of PNG, JPG or BMP frames. Builds a pixel grid with one color channel per block and plays it frame by frame with spawn triggers that only change blocks that differ. Adds a Video button to the editor pause menu and an options window for hiding the player, keeping the video on screen, looping, ending the level and a black background.
